# PharmaTrace 360 — System Test Cases & Verification Matrix

> **Course:** 2nd-Year B.Tech DBMS Project.  
> **Purpose:** Comprehensive test suite validating database integrity, least-privilege security, authentication, transaction atomicity, query indexing, and public drug authentication.  
> **Instructions for Evaluator/Tester:** Execute the steps described for each test case and record the execution outcome in `Result (PASS/FAIL)` along with the corresponding evidence screenshot filename in `Evidence (screenshot name)`.
