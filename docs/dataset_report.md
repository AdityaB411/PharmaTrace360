## 5. Data Cleaning Notes (`data/clean/`)

1. **From A-Z file:** Extracted 15 target medicines using exact salt matching. Flattened `use0`-`use4` into semicolon-separated `uses`. Normalised Unicode hyphens to ASCII `-`. Filtered out discontinued, multi-ingredient, and incomplete rows.
2. **From medicine_data:** Matched by exact salt key (before parenthesis). Skipped all `+`-containing (combination) products. Parsed `drug_interactions` JSON -> plain drug name list (max 5). Deduplicated automatically by taking first matching row.
3. **Unicode hyphens:** All `U+2010`-`U+2015` and `U+2212` replaced with plain ASCII `-` (U+002D).
4. **Storage note:** Generic `"Store below 25 C, in a cool dry place, away from light"` applied to all 15. Labelled `source_note = "demo storage text"` so it is never confused with real labelling data.
5. **Output:** `data/clean/medicines_15.csv` — UTF-8, 15 data rows, 15 columns, ready for SQL import.
6. **Script:** `data/clean/build_medicines_15.py` — reproducible, reads raw files as read-only.

## 6. Known Limitations

| Limitation | Detail |
|---|---|
| **Third-party data provenance** | All medicine, manufacturer, ingredient, uses, and side-effect data is scraped from third-party sources and published on Kaggle. The project team has not independently verified accuracy or completeness. |
| **Prices and availability as of 2022** | The `price(Rs)` column in the A-Z file and `product_price` in `medicine_data.csv` reflect market prices and product availability circa 2022. Current prices and availability may differ significantly. |
| **Licences not verified** | The licences under which the Kaggle datasets were published have not been formally verified for compliance with this project's use case. The datasets are used here for educational demonstration only. |
| **Demonstration data only** | All data in this project — including the 15 cleaned medicines, interaction lists, storage notes, and simulated batch/QA/QR records — is for a **2nd-Year B.Tech DBMS demonstration project only**. It must not be used for any clinical, regulatory, or patient-facing purpose. |
